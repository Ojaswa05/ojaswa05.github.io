## Run the portfolio locally

The site is static and has no package installation or build step.

1. Clone or download this repository.
2. From the project directory, start a local web server:

   ```bash
   python -m http.server 8000
   ```

3. Open [http://localhost:8000](http://localhost:8000) in your browser.

You can also open `index.html` directly, but a local server is recommended for a browser-like preview.

## Deploy with GitHub Pages

This site is intended for the GitHub Pages repository [`Ojaswa05.github.io`](https://github.com/Ojaswa05/Ojaswa05.github.io).

1. Push the site files to the repository's `main` branch, keeping `index.html` at the published root.
2. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and the root (`/`) folder, and save.
3. Once GitHub Pages finishes publishing, visit [https://ojaswa05.github.io](https://ojaswa05.github.io).
